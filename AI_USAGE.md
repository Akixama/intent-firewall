# AI assistance disclosure

This project was developed with assistance from OpenAI Codex. AI assistance was used for:

- exploring and refining the product concept;
- drafting and implementing portions of the React/TypeScript interface;
- implementing and testing the deterministic policy simulator and server route;
- improving UI copy, interaction details and accessibility;
- researching public technical documentation;
- preparing deployment configuration and project documentation; and
- drafting the architecture and demo materials.

The project owner directed the concept, selected the product scope, made feature and design decisions, reviewed the interactive behavior, tested the deployed experience, and approved publication. AI-generated suggestions were iteratively evaluated and changed rather than accepted as autonomous authority.

No AI-generated output controls a real wallet in this prototype. The transaction outcome shown in the demo is produced by explicit TypeScript policy rules, and live preflight status comes from the Base Sepolia RPC response.
